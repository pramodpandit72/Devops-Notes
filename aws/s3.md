# S3

## Overview
S3 is object storage for files and backups.

## Key ideas
- Buckets are containers for objects
- Objects have keys (paths)

## Important commands
- `aws s3 ls` use: list buckets
- `aws s3 cp file s3://bucket/` use: upload a file

## Interview questions with answers
- Q: What is a bucket?
	A: A top-level container for objects in S3.
- Q: How do you make a bucket private?
	A: Block public access and control access with bucket policies and IAM.
