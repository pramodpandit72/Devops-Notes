# CI/CD Concepts

## Overview
CI is about merging code often. CD is about delivering safely.

## Key ideas
- Build, test, and deploy automatically
- Fast feedback and reliable releases

## Interview questions with answers
- Q: What is CI?
	A: Continuous Integration, merging and testing code often.
- Q: What is the difference between continuous delivery and continuous deployment?
	A: Delivery keeps releases ready; deployment releases automatically.
