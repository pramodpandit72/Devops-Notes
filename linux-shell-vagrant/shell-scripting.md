# Shell Scripting

## Overview
Shell scripts automate repeated tasks.

## Key ideas
- Scripts are plain text files.
- Start with a shebang: `#!/bin/bash`

## Basic example
```bash
#!/bin/bash
NAME="DevOps"
echo "Hello $NAME"
```

## Important commands
- `bash script.sh` run a script
- `chmod +x script.sh` make it executable
- `./script.sh` run it directly
