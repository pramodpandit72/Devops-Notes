# Vagrant

## Overview
Vagrant creates repeatable local dev environments using virtual machines.

## Key ideas
- Vagrantfile defines the VM
- Providers can be VirtualBox, Hyper-V, etc.

## Important commands
- `vagrant init` create a Vagrantfile
- `vagrant up` start the VM
- `vagrant ssh` connect to the VM
- `vagrant halt` stop the VM
- `vagrant destroy` remove the VM
