# Vagrant

## Overview
Vagrant creates repeatable local dev environments using virtual machines.

## Key ideas
- Vagrantfile defines the VM
- Providers can be VirtualBox, Hyper-V, etc.

## Important commands
- `vagrant init` use: create a Vagrantfile
- `vagrant up` use: start the VM
- `vagrant ssh` use: connect to the VM
- `vagrant halt` use: stop the VM
- `vagrant destroy` use: remove the VM

## Interview questions with answers
- Q: Why use Vagrant?
	A: It creates repeatable dev environments across machines.
- Q: What is a Vagrantfile?
	A: The config file that defines the VM settings.
