# Maven Basics

## Overview
Maven is a build tool for Java projects.

## Key ideas
- `pom.xml` defines dependencies and build steps
- Uses a standard lifecycle

## Important commands
- `mvn -v` Maven version
- `mvn clean` remove build output
- `mvn test` run tests
- `mvn package` build the artifact

## Interview questions
- What is a `pom.xml`?
- What does `mvn clean` do?
