# Project: Dockerized App

## Goal
Containerize a simple app and run it locally.

## Steps
1) Create a basic app (any language).
2) Write a Dockerfile.
3) Build the image.
4) Run the container.

## Important commands
- `docker build -t myapp .`
- `docker run -p 8080:8080 myapp`

## Interview questions
- What files are required to dockerize an app?
- How do you pass environment variables to a container?
