# DevOps Learning Roadmap

## Phase 1: Foundations
- Linux basics and shell
- Git and GitHub
- YAML, JSON, and Bash

## Phase 2: Core Tools
- Docker and container basics
- CI/CD concepts
- Maven and Jenkins

## Phase 3: Cloud and Infra
- AWS basics (EC2, S3, IAM, VPC)
- Ansible basics

## Phase 4: Orchestration
- Kubernetes basics (pods, deployments, services, ingress)

## Phase 5: Practice
- Build a dockerized app
- Create a CI/CD pipeline
- Deploy to Kubernetes

## Suggested order
1) linux-shell-vagrant
2) yaml-json-bash
3) git-github
4) docker
5) ci-cd
6) maven-jenkins
7) aws
8) ansible
9) kubernetes
10) projects
