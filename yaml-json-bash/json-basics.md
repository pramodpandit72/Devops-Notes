# JSON Basics

## Overview
JSON is a common data format for APIs and configs.

## Example
```json
{
  "name": "app",
  "port": 8080
}
```

## Important commands
- `jq '.' file.json` pretty print JSON
- `jq '.name' file.json` read a field
